# 透明便签 1.0.5

Windows 桌面透明悬浮便签，背景可调透明度，文字保持清晰，支持鼠标穿透、置顶、多张便签及系统托盘恢复编辑。

从 [Releases](https://github.com/z2476720314-sys/DesktopStickyNotes/releases/latest) 下载程序包，解压到可写目录，双击 `DesktopStickyNotes.exe`。可为 EXE 创建桌面快捷方式；便签图标已内嵌在 EXE，程序包同时提供 `app.ico`。

| 操作 | 使用方式 |
| --- | --- |
| 写便签 | 直接在正文输入，停止输入 0.6 秒后自动保存；Ctrl+S 立即保存 |
| 显示工具栏 | 单击便签或左上角顶部区域；鼠标经过不显示，拖动也不显示；点击其他窗口后隐藏 |
| 移动 | 按住左上角顶部区域拖动，工具栏隐藏时也可拖动 |
| 缩放 | 拖动右下角斜线 |
| 新建 | 点击 ＋，或按 Ctrl+N |
| 置顶 | 点击图钉；带斜线的图钉表示未置顶 |
| 字体颜色 | 点击调色板图标，从系统颜色选择器任选正文颜色；工具栏、标题、提示和保存状态保持原色；自动保存，重启后恢复 |
| 鼠标穿透 | 单击便签显示工具栏，再点击光标箭头图标；便签继续显示，点击可到达下方窗口；右键托盘也可开启所有便签的穿透 |
| 恢复编辑 | 双击托盘图标或桌面快捷方式，关闭穿透并恢复编辑；托盘右键菜单提供「显示并恢复编辑」 |
| 透明度 | 点击 ⋯ → 背景透明度，提供仅文字、85%、78%、65%、35%、0% |
| 字号与文字颜色 | 点击 ⋯ → 文字大小，或切换深色/白色文字 |
| 隐藏 | 点击 ×；便签内容保留 |
| 找回 | 双击桌面快捷方式或系统托盘图标；右键托盘可显示并恢复编辑 |
| 删除 | 点击 ⋯ → 删除这张便签，确认后删除 |
| 退出 | 点击 ⋯ → 退出程序，或右键托盘 → 退出；退出前完成保存 |

默认置顶、白色文字、背景透明度 78%。亮色壁纸可切换深色文字，也可通过调色板选择任意字体颜色。退出后再次启动，会恢复内容、位置、大小与外观设置。

穿透状态按便签自动保存，重启后保留。穿透开启时，鼠标点击和拖动会传给下方窗口，因此不能直接编辑或移动这张便签；先从托盘或快捷方式恢复编辑，再进行修改。新建便签及旧版本数据默认可编辑。

EXE、桌面快捷方式、窗口和系统托盘统一使用便签图标。ICO 包含 16、20、24、32、40、48、64、128、256 像素版本。便签从任务栏和 Alt+Tab 切换列表隐藏，保留系统托盘图标；可从托盘或桌面快捷方式找回。

数据保存在 EXE 同目录的 `Data\notes.xml`，上一次保存保留为 `Data\notes.xml.bak`。文件损坏且备份可用时，从备份恢复并保留损坏原文件；两份文件均不可读时停止启动，不覆盖原有内容。恢复的是上一次备份，不保证包含最后一次修改。

保存失败时显示「保存失败 · Ctrl+S 重试」，内容暂留在窗口中。检查目录写权限和磁盘空间后重试。仅在保存成功后退出。请把程序保存在可写目录；整体移动程序文件夹时，一并保留 Data。

使用 Windows 自带 .NET Framework / WPF，无需安装 Python、Node.js 或下载额外运行时。不启用开机启动，不接入云端。

## 开发与验证

克隆源码后，在项目目录运行以下命令。建议将源码放在可写的非系统盘目录。

```powershell
.\build.ps1
.\UiChecks.ps1
```

`Checks.cs` 检查真实文件保存、中文/换行/emoji、外观配置、隐藏与穿透状态、旧数据兼容、损坏恢复和写入错误。`UiChecks.cs` 运行正式 EXE，使用隔离数据目录和专用背景窗口检查真实输入、悬停隐藏、单击显示、隐藏状态拖动、鼠标缩放、透明合成、置顶、正文颜色与界面颜色分离、跨进程实际鼠标穿透、重启保留穿透、恢复编辑、多个便签和独占写入锁。测试结束后清理隔离数据。`UiChecks.ps1 -InspectProcessId <PID>` 在本机桌面入口检查任务栏隐藏、应用图标及实际托盘双击恢复编辑。

构建结果位于 `dist`，编译及测试缓存位于 `.build`。可通过 `build.ps1 -OutputDirectory <目录> -BuildDirectory <目录>` 和 `UiChecks.ps1 -Exe <EXE路径> -BuildDirectory <目录>` 调整输出路径。原生窗口截图位于 `.build/evidence`，只截便签与测试背景；UI 检查需要交互式 Windows 桌面，会使用鼠标并显示专用测试背景。

`-InspectProcessId` 是包含桌面快捷方式的专项检查：运行前需在当前用户桌面创建名为 `透明便签.lnk`、指向待检查 EXE 的快捷方式。普通运行和完整 UI 检查不要求创建快捷方式。

正式发布包不包含便签数据、源码备份、日志或测试缓存。首次运行会自动创建 `Data`；升级时保留已有 `Data` 目录。

未验证多屏不同缩放率、用户实际中文输入法及不同 Windows 用户同时登录的完整交互。独占写入锁已用竞争进程验证。

透明实现依据：[Microsoft WPF 窗口透明文档](https://learn.microsoft.com/en-us/dotnet/api/system.windows.window.allowstransparency?view=netframework-4.8.1)和[背景画刷透明文档](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/how-to-make-a-uielement-transparent-or-semi-transparent)。已检索 GlassNotes 和 clicknote；本版直接使用系统平台功能，无第三方源代码或依赖。

鼠标穿透使用 Windows 分层窗口的 `WS_EX_TRANSPARENT`，依据 [Microsoft 分层窗口命中测试说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)。
